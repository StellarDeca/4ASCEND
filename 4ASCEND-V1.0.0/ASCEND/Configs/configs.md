# 配置文件  
-----------------------------------------------
## init.json
**init.json**为初始化的配置文件,**ConfigManager**将直接读取这个json文件并加载init中记录的其它配置文件  
---------------------
## 格式化选项
除去**init**文件之外,每个配置文件都必须包含**format**选项,该选项包含两个参数:
1. ***data***: 是否需要对配置文件进行数据格式化选项,将最深层的数组转换为python的元组;  
2. ***path***: 是否需要对配置文件进行路径格式化选项,将配置文件中的相对路径转变为绝对路径;  
-----------------------------------------------
## 各项配置文件介绍
- **AnimationsConfig**: 动画参数
   - **coordinate-tip**: 放置棋子的坐标提示的旋转速率
   - **result-players**: 结算界面玩家头像参数
   - **turn-sign**: 回合标志的参数 
   - ***除非特别说明,数据的基准画布大小均为棋盘大小:1920x1080***
-----------------------------------------------
- **AssetsConfigs**: 游戏所需资源的参数  
   - **font**: 字体参数  
   - **audios**: 游戏的音频资源路径参数  
   - **images**: 图像资源路径参数  
   - **img-size**: 图像大小参数  
   - **keyframe-animation**: 关键帧资源路径  
   - **keyframe-size**: 关键帧图像大小参数  
-----------------------------------------------
- **ItemsConfig**: 游戏参数  
   - **plants**: 魔力植物配置参数  
   - **players**: 玩家基础血量参数  
-----------------------------------------------
- **UIConfig**: 游戏的界面参数
   - **chessboard**: 棋盘界面参数  
   - **players**: 玩家头像与玩家血量条的参数  
   - **result-ui**: 结算界面的参数
   - **start-ui**: 起始界面的参数
   - **suspend-ui**: 暂停界面的参数
